# Security policy

Please **don't open a public issue** for security problems.

Report them privately through GitHub:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the impact. We'll reply within a few days and
credit you in the fix unless you'd rather stay anonymous.

In scope: launchwright.app, platform.launchwright.app, the waitlist API, and the code in this repo.
